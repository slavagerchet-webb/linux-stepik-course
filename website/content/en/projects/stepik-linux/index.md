<h2>Stepik Course: Introduction to Linux</h2>

<p class="lead">
This project presents the completion of the Stepik external course “Introduction to Linux”. The materials include reports, presentations, screencasts, source archives, a certificate and a project page.
</p>
</section>

## Project Description

The course was completed in three stages:

1. Introduction.
2. Working on a server.
3. Advanced topics.

For each stage, reports, presentations, screenshots, source archives and video recordings were prepared.

## Project Goal

The goal of the project is to confirm the completion of the external course, prepare reproducible reporting materials and publish the results on GitHub, GitHub Release and a personal academic website.
