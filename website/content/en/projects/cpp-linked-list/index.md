<h2>C++ Laboratory Work: Singly Linked List</h2>

</p>

## Project Description

The program implements a list of goods. Each node contains the product name, amount, price and a pointer to the next node.

## Goal

The goal is to practice dynamic data structures, pointers, references, dynamic memory allocation and functions in C++.

## Implemented Features

<div class="grid">
  <div class="card">
    <h3>Data structure</h3>
    <p>The <code>Tovar</code> structure contains <code>name</code>, <code>amount</code>, <code>price</code> and <code>next</code>.</p>
  </div>
  <div class="card">
    <h3>List operations</h3>
    <p>The program implements insertion at the beginning, insertion at the end, insertion before and after a node, deletion and list output.</p>
  </div>
  <div class="card">
    <h3>Memory management</h3>
    <p>List nodes are created dynamically and deleted correctly using a cleanup function.</p>
  </div>
</div>
