## Project Description

The program contains two user-defined classes: <code>vect</code> for vectors and <code>matr</code> for square matrices. It demonstrates constructors, destructors, copy constructors, assignment operators and overloaded arithmetic operations.

## Goal

The goal is to practice object-oriented programming, dynamic memory management and operator overloading in C++.

## Implemented Features

<div class="grid">
  <div class="card">

  <div class="card">
