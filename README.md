## Описание проекта

Данный репозиторий содержит материалы по прохождению внешнего курса Stepik «Введение в Linux».

Курс был выполнен по трём этапам:

1. Этап 1 - Введение.
2. Этап 2 - Работа на сервере.
3. Этап 3 - Продвинутые темы.

По каждому этапу подготовлены:

- отчёт в форматах Markdown, PDF и DOCX;
- презентация в форматах Markdown, HTML и PDF;
- архив исходных материалов;
- скриншоты формулировок заданий и подтверждений прохождения;
- видеозаписи прохождения курса, создания отчёта, создания презентации и защиты презентации.
