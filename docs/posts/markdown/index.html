Язык разметки Markdown

Markdown - это лёгкий язык разметки, который используется для подготовки текстовых документов, README-файлов, отчётов и презентаций.

В рамках проекта Markdown применялся для оформления отчётов по внешнему курсу. После этого исходные файлы были преобразованы в PDF и DOCX. Такой подход удобен тем, что один исходный файл можно хранить в Git и использовать для получения нескольких форматов.

Основные преимущества Markdown:

  • простой синтаксис;
  • удобство хранения в Git;
  • возможность преобразования в PDF, DOCX и HTML;
  • хорошая читаемость исходного текста.
