Управление версиями Git

Git - это система контроля версий, которая позволяет сохранять историю изменений проекта. Она особенно полезна при подготовке отчётов, презентаций и сайта, потому что все изменения можно фиксировать отдельными коммитами.

В проекте Git используется для хранения:

  • исходных файлов отчётов;
  • презентаций;
  • материалов сайта;
  • архивов исходных данных;
  • итоговых PDF и DOCX файлов.

GitHub используется как удалённый репозиторий и как платформа для публикации сайта через GitHub Pages.
