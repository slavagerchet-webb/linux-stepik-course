Пост по прошедшей неделе

На прошедшей неделе была выполнена основная работа по прохождению внешнего курса Stepik «Введение в Linux». Были подготовлены скриншоты контрольных мероприятий, оформлены отчёты и презентации по трём этапам.

Основные выполненные действия:

  • прохождение трёх этапов курса;
  • подготовка отчётов в Markdown, PDF и DOCX;
  • подготовка презентаций в Markdown, HTML и PDF;
  • запись видеозащит презентаций;
  • подготовка материалов для GitHub и GitHub Pages.

Эта работа позволила закрепить навыки работы с Linux, терминалом, сервером, bash-скриптами и инструментами оформления документации.
