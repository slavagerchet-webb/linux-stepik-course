Внешний курс Stepik «Введение в Linux»

Описание проекта

Проект посвящён прохождению внешнего курса Stepik «Введение в Linux». Курс был выполнен по трём этапам:

  1. Введение.
  2. Работа на сервере.
  3. Продвинутые темы.

По каждому этапу были подготовлены отчёт, презентация, скриншоты выполнения заданий, архив исходных материалов и видеозаписи. Материалы размещены в репозитории GitHub, на странице проекта собственного сайта и в виде отдельных файлов.

Цель проекта

Цель проекта - подтвердить прохождение внешнего курса, оформить результаты в виде отчётов и презентаций, а также разместить итоговые материалы на GitHub и на собственном сайте научно-инженерного работника.

Техническая реализация сайта

Сайт реализован как статический сайт на базе генератора Hugo и размещается через GitHub Pages. Структура сайта оформлена по логике персонального академического сайта: биография, интересы, образование, навыки, опыт, достижения, научные ресурсы, посты и проекты.

Используемые ориентиры:

  • Hugo: https://gohugo.io/
  • Wowchemy Hugo Themes: https://github.com/wowchemy/wowchemy-hugo-themes
  • Hugo Academic Theme: https://github.com/wowchemy/starter-hugo-academic
  • GitHub Pages: https://pages.github.com/

Материалы по этапам

Этап 1 - Введение

На первом этапе были изучены базовые сведения о Linux, работа с терминалом, запуск программ, ввод и вывод данных, скачивание файлов, архивы и поиск по файлам.

Этап 2 - Работа на сервере

На втором этапе были изучены удалённые серверы, SSH-ключи, передача файлов, запуск программ, управление процессами, многопоточные приложения и tmux.

Этап 3 - Продвинутые темы

На третьем этапе были изучены редактор vim, bash-скрипты, переменные, условия, циклы, функции, поиск файлов, grep, sed и регулярные выражения.
